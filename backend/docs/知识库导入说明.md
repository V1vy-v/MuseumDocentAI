# 知识库导入说明（全国博物馆资料馆 v3）

## 来源

《全国博物馆资料馆 v3·文物条目扩充版》语料库：底库为国家文物局全国博物馆年度报告（2025）
中 7,188 家备案博物馆，另对能从馆方公开页面核实的展品建立"一物一文件"的文物卡。
原始规模：9,648 份 Markdown、1,339 张实物图、71 MB。

## 导入时做的三轮删减

课程作业只需覆盖典型场景，不追求全国完整度，因此按三档逐步收敛：

| 轮次 | 处理 | 结果 |
|---|---|---|
| 第一轮 | 删除 5,371 家"未定级且无文物卡"的博物馆卡（内容只有馆藏概况 + 展品查阅说明，空洞） | 博物馆卡 7,188 → 1,817 |
| 第一轮 | 不导入 1,339 张实物图（文本 RAG 用不到，避免仓库膨胀 42 MB） | 图片全部删除 |
| 第二轮 | 只保留 **一级博物馆**（327 家，都是知名馆），其余二级/三级/未定级全部删除 | 博物馆卡 → 327 |
| 第二轮 | 文物卡只保留一级馆的，每馆最多 5 件（取文件最丰富的） | 文物卡 2,459 → 276 |
| 第三轮 | 补回 12 件"名品"文物卡（越王勾践剑、曾侯乙编钟、后母戊鼎、四羊方尊、清明上河图、千里江山图、五牛图、步辇图、韩熙载夜宴图、洛神赋图、兰亭序、金缕玉衣等） | 文物卡 → 288 |

**最终：616 份 Markdown（327 个博物馆卡 + 288 个文物卡 + 1 份语料说明），3.4 MB。**

> 原始完整语料仍在 `C:\Users\Itte1\Downloads\全国博物馆资料馆_v3`，需要扩充时按同样规则从源库拷回即可。

## 目录结构

```
knowledge_base/全国博物馆资料馆/
├── museums/<省份>/<博物馆>.md           # 一级博物馆卡（文物介绍/历史背景/展厅分布/书画知识）
├── artifacts/<省份>/<博物馆>/<文物>.md    # 文物卡（一物一文件，H1 即文物名）
├── museums_index.csv                    # 原语料总目录（含等级、官网、文物条目数）
├── artifacts_index.csv                  # 原语料文物索引
└── README.md                            # 语料库原始说明（后端跳过，不参与索引）
```

## 检索方式：当前为「关键词模式」

原本计划建向量索引（zvec + 火山方舟 `doubao-embedding-vision`，2048 维）。
实际执行时该账号的 embedding 接口**持续返回 429（AccountRateLimitExceeded）**，
指数退避重试后仍无法完成建库，因此关闭了向量索引：

```ini
# backend/.env
RAG_VECTOR_ENABLED=0
```

检索自动走关键词模式（分词匹配），实测效果（616 份资料）：

| 提问 | 命中来源 |
|---|---|
| 越王勾践剑是什么时期的文物？ | 越王勾践剑 ✓ |
| 曾侯乙编钟在哪个博物馆 | 曾侯乙编钟 + 湖北省博物馆 ✓ |
| 故宫博物院有什么名画 | 张择端清明上河图卷 / 千里江山图 ✓ |

> 关键词模式的局限：口语化改写、同义表达、馆级信息类问题（如"开放时间"）命中率低于向量检索。

## 向量索引的恢复方法（配额恢复后）

代码侧已备好限速与重试（`EMBED_DELAY_SECONDS` 批间隔、`EMBED_RETRIES` 429 重试次数），
配额恢复后执行：

```powershell
cd backend
# 1. 打开向量索引
(Get-Content .env) -replace '^RAG_VECTOR_ENABLED=0$', 'RAG_VECTOR_ENABLED=1' | Set-Content .env -Encoding utf8
# 2. 清掉半成品索引（如果存在）
Remove-Item data\zvec_kb -Recurse -Force -ErrorAction SilentlyContinue
# 3. 启动服务，索引会自动建好
.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
```

616 份资料约切出 5,000~6,000 块（每块约 300 字），需要约 550 次 embedding 请求。

## 其他注意事项

- **检索阈值需重标**：`DENSE_MAX_DISTANCE`（默认 0.62）是在旧的小库下标定的，启用向量检索后需重新标定。
- **提示词清单已限量**：后端会把"资料清单"注入提示词；资料变多后整份注入会推高 token，
  已加 `CATALOG_MAX_TITLES`（默认 120），超出部分用"等共 N 份资料"概括。
- **"本馆"定位**：资料覆盖多省名馆，而 APP 人设是"本馆讲解员"；演示时建议固定问某个馆的文物，
  或把 System Prompt 改为"全国博物馆资料库"的定位。
- 资料来源：各馆公开页面与国家文物局年度报告，仅用于课程演示。
