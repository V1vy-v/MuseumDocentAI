# 全国博物馆资料馆（v3·文物条目扩充版）

面向“基于 RAG 的博物馆导览问答机器人”的语料库。底库为国家文物局全国博物馆年度报告（2025 年）的 **7,188 家备案博物馆**；在博物馆资料卡之外，对能从馆方公开页面核实的展品建立 **一物一文件的文物卡**，作为 RAG 的高精度检索单元。

## 目录结构

```
museum_archive/
├── README.md
├── museums_index.csv              # 7,188 家博物馆总目录
├── artifacts_index.csv            # 2,459 条文物索引
├── museums/
│   └── <省份>/<博物馆>.md          # 博物馆资料卡（馆史、展厅、参观、书画）
├── artifacts/
│   └── <省份>/<博物馆>/<文物>.md    # 单件文物卡（名称、年代、类别、描述、来源）
└── assets/
    └── artifacts/<博物馆ID>/<hash>.jpg  # 馆方藏品页的实物图
```

- 文件名即规范名称；同一省份内不重名。
- 博物馆卡不再用馆舍外观图充当“文物介绍”；文物图只来自馆方藏品页的实物图。
- 文物卡按“一物一文件”组织，H1 就是文物名，适合回答“越王勾践剑是什么时期”“这件东西在哪个馆”等问题。

## 博物馆资料卡结构

每份固定包含四个二级标题，便于按标题切块：

1. `## 文物介绍（图文）`
   - 一句话定位与藏品总量；
   - 有可核实器物名时，每件文物一个 `### 文物名`，下列年代、类别、馆藏、简介，部分带馆方实物图；
   - 没有器物名时，用 `### 馆藏概况` + `### 展品查阅说明`，明确不编造。
2. `## 历史背景资料`
   - 建馆时间、馆址、沿革、建筑与重要节点。
3. `## 展厅分布与参观路线`
   - 展厅与陈列、参观信息表、建议路线。
4. `## 书画知识`
   - 本馆书画藏品 / 馆方资料中的书画信息；
   - 所在地域书画脉络；
   - 针对本馆类型的观赏要点，并点名本馆，避免全省同一段话。

文末 `## 资料来源` 标注国家文物局年度报告、官网等。

## 文物卡结构

```markdown
# 越王勾践剑

> 馆藏：湖北省博物馆 · 湖北省·武汉市·武昌区

> 资料馆文物编号：<博物馆ID>-01

## 基本信息
- 年代 / 类别 / 馆藏单位 / 所在地

## 文物介绍
…

## 参观与检索提示
…

## 资料来源
- [馆方藏品页](…)
```

## 数据来源

- 主体：国家文物局全国博物馆年度报告 2025（`work/data/museums_2025.json`）。
- 重点馆藏：`work/data/artifact_seed.json` 的人工整理条目（47 家馆、113 件）。
- 故宫博物院：`scripts/dpm_crawl.py` 调用馆方藏品检索接口，覆盖 23 个门类，写入 1,276 条藏品记录，经清洗后 1,264 条文物卡，描述与实物图均来自馆方藏品页。
- 其他博物馆：`scripts/deep_crawl.py` 抓取官网藏品/展览栏目、分页列表与文物详情页，共 1,286 个站点结果，221 个站点有可用结果，产出 1,837 条候选，经名称/描述清洗后并入。
- 结构化补充：`work/crawl/*.json` 中“名称/年代/材质/简介”字段。
- 不使用百度百科的自动抓取结果：其条目页与搜索页均返回 403/验证码，无法在 7,188 馆规模上稳定、合规地批量获取。

## 清洗规则

- 去除页脚、版权、ICP/公网安备、电话、邮箱、网址、导航、打印/返回顶部等模板文本。
- 去除政治新闻、领导视察、回信贺信、捐赠者名单、征集公告、学生团体预约、个人申报材料等噪声。
- 文物名过滤活动/展览/新闻/政策/栏目名（如“临时展览”“党建工作”“馆藏精品”“文物保护法”），拒绝把网页标题当文物。
- 参观信息只保留开放时间、预约、交通、地址等可操作内容；官网参观页中大量预约政策话术已剔除。
- 无有效信息时使用中性描述，不编造馆藏数字、文物名或书画藏品。

## 已知限制

- 4,556 家博物馆没有官网地址，内容主要来自登记简介，详略受原始资料限制。
- 2,459 条文物卡集中在 394 家馆；其余 6,794 家只有馆藏概况，没有逐件器物名。要做到“每馆每器”需要馆方藏品目录或授权数据，公开网页无法覆盖。
- 上博、南博、辽博、三星堆、河南博物院等官网为 JS 渲染或反爬限制，自动抓取失败或只得到少量条目；故宫、湖北省博、国博、徐州博物馆、青岛啤酒博物馆等静态/接口型站点覆盖较好。
- 部分文物卡只有 1–2 句简介；馆方页面本身很简略，未做二次扩写，避免编造。
- 故宫文物卡的“类别”由名称推断，个别陶器可能被归到青铜器；描述与年代仍来自馆方页面。
- 书画部分为“地域脉络 + 馆型观赏要点 + 本馆提示”，不是每馆独立的学术研究；有实际书画藏品的馆会直接列出作品。
- 开放时间、预约规则会变化，资料卡反映采集时点，实际参观以馆方公告为准。

## 复现

```bash
python work/fetch_list.py
python work/parse_registry.py
python scripts/crawl_sites.py --workers 12
python scripts/deep_crawl.py --levels 一级 --workers 10
python scripts/deep_crawl.py --levels 二级,三级 --workers 18 --max-details 12 --max-lists 8
python scripts/dpm_crawl.py 5
python scripts/build_archive_v3.py --clean --out museum_archive
```

依赖：Python 3.10+、requests、beautifulsoup4、lxml、trafilatura、Pillow。

## 导入 RAG 知识库

仓库 `repo/backend/knowledge_base/README.md` 约定：仅支持 `.md` / `.txt`，文件名作为标题，按标题切块，图片忽略，`README.md` 跳过。

```bash
mkdir -p repo/backend/knowledge_base/全国博物馆
cp -r museum_archive/museums/* repo/backend/knowledge_base/全国博物馆/
cp -r museum_archive/artifacts/* repo/backend/knowledge_base/全国博物馆/
```

重启后端触发增量索引。文物卡建议与博物馆卡一起入库：前者提供“一物一答”的高精度块，后者提供馆史、参观信息与馆藏概况。

## 校验

- 7,188 份博物馆 Markdown，32 个省级目录，无重复文件名。
- 四类必需标题覆盖率 100%，无少于 900 字符的残缺文件。
- 文物卡 2,459 份，字段结构完整；`artifacts_index.csv` 与文件数一致。
- 1,339 个图片引用全部可解析，无断链；已删除未引用图片。
- 书画段 7,187/7,188 份内容哈希不同（仅 1 组重复）。
- 正文字符数：博物馆卡最短 984、中位数 1,389、最长 10,422；文物卡最短 306、中位数 586、最长 1,171。
