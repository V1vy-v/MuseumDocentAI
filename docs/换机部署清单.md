# 换一台电脑当后端：部署清单

> 适用场景：把后端从开发机搬到另一台 Windows 电脑（组员机器、答辩用的电脑、云主机等）。
> 目标：clone 完代码后，**10 分钟内**把这台机器跑成可用的后端。

---

## 0. 先确认这台机器够不够格

| 条件 | 要求 | 怎么查 | 不满足会怎样 |
|---|---|---|---|
| 操作系统 | **Windows x64** | `[Environment]::Is64BitOperatingSystem` | Linux/macOS 没有 zvec 的预编译包，装不上 |
| Python | **3.14（64 位）** | `py -0p` / `python -V` | zvec 只发布 `cp314-win_amd64` 轮子，其它版本必然失败 |
| 网络 | 能访问 PyPI、`api.deepseek.com`、`api.siliconflow.cn` | 浏览器能开 `https://api.deepseek.com` | 装不了依赖 / 问答无法回答 |
| 磁盘 | ≥ 1 GB 空闲 | — | venv ~200MB + 索引 ~50MB + 资料 12MB |

> ⚠️ 如果这台机器只有 Python 3.12/3.13，**不要硬试**。要么装一个 3.14（可以并存，用 `py -3.14` 指定），
> 要么用 `uv venv --python 3.14 .venv` 单独拉一个解释器。

## 1. 一键初始化（推荐）

```powershell
git clone <仓库地址> MuseumDocentAI
cd MuseumDocentAI\backend

# 先体检（不改任何东西）
scripts\setup_backend.cmd -CheckOnly

# 正式初始化：建 venv → 装锁定依赖 → 检查 .env → 首次建索引
scripts\setup_backend.cmd
```

脚本会依次检查/处理：Python 版本与位数、虚拟环境、依赖与 `requirements-lock.txt` 是否一致、
`.env` 是否存在且为 UTF-8、关键配置项是否为空、向量索引是否存在。
任一步不满足都会给出**明确的中文提示**，而不是装到一半炸掉。

常用参数：

```powershell
scripts\setup_backend.cmd -CheckOnly     # 只检查
scripts\setup_backend.cmd -SkipIndex     # 跳过建索引（已有索引时用）
scripts\setup_backend.cmd -Mirror ""     # 不用国内镜像，走官方 PyPI
```

> 为什么用 `.cmd` 而不是直接跑 `.ps1`：Windows 默认执行策略禁止运行未签名的 PowerShell 脚本
> （报 `UnauthorizedAccess` / `无法加载文件`）。`.cmd` 里用 `-ExecutionPolicy Bypass`
> 只对这一次调用放宽，不改系统设置。

## 2. 手动流程（理解原理 / 排错用）

```powershell
cd backend

# ① 虚拟环境（用 py 启动器指定版本，避免 PATH 里的假 python）
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip -i https://pypi.tuna.tsinghua.edu.cn/simple

# ② 依赖（锁定版本，别用裸 requirements.txt）
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# ③ 密钥文件（.env 不进 git，必须自己建）
Copy-Item .env.example .env
notepad .env        # 填 DEEPSEEK_API_KEY / EMBED_API_KEY 等，保存为 UTF-8

# ④ 建索引（约 40 秒，会消耗 embedding 额度）
.\.venv\Scripts\python.exe scripts\build_index.py

# ⑤ 启动（必须 --host 0.0.0.0）
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### `.env` 至少要有这些

| 变量 | 用途 | 不填的后果 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 文本问答 / 语音识别 / 语音合成 | 问答直接失败 |
| `EMBED_API_KEY` + `EMBED_BASE_URL` + `EMBED_MODEL` | 向量化 | 检索退回关键词模式（能用，但准确率下降） |

当前生产配置是 SiliconFlow `BAAI/bge-m3`（**1024 维**）。`EMBED_MODEL` 换了就必须重建索引
（`scripts\build_index.py`），否则维度和索引对不上，检索会直接报错。

## 3. 哪些东西不在 git 里

| 路径 | 内容 | 换机后 | 想保留怎么办 |
|---|---|---|---|
| `backend/.env` | 密钥 | **必须重建** | 手动拷（注意仍是 UTF-8） |
| `backend/.venv/` | 虚拟环境 | 重建 | 别拷，跨机器会坏 |
| `backend/data/chat.db` | 历史对话（SQLite） | 空的 | 拷这个文件（可带着旧对话） |
| `backend/data/zvec_kb*` | 向量索引 | 首次启动自动重建 | 可以拷，但文件 mtime 变了可能仍会重建；不如让它重建 |
| `.tools/` | 开发期的临时脚本 | 不需要 | — |

资料本体 `backend/knowledge_base/`（584 份 md + 58 张图 + CSV，647 个文件）**在 git 里**，clone 就有。

## 4. 手机 / 模拟器怎么连过来

### 真机

1. 手机和电脑连**同一个 WiFi**
2. 电脑查 IP：`ipconfig` → 找到 `IPv4 地址`，例如 `192.168.1.8`
3. APP 右上角 **⚙** 填 `http://192.168.1.8:8000`
4. 防火墙放行（见下）

> 没有共同 WiFi 的场合（例如在教室演示）：**手机开热点，电脑连手机热点**，
> 电脑会拿到 `192.168.43.x`，APP 填这个地址即可，同时热点也提供了访问大模型所需的外网。

### 模拟器（MuMu）

```powershell
adb connect 127.0.0.1:16384
adb -s 127.0.0.1:16384 reverse tcp:8000 tcp:8000
```
APP 里地址**留空**即可（会自动用 `127.0.0.1`）。

> Android Studio 的 AVD 走 `10.0.2.2`。注意：开了 Clash 等代理时 `10.0.2.2` 常常连不上，
> 用 `adb reverse` 更稳。

### 防火墙（首次运行会弹窗，点了取消就连不上）

```powershell
# 需要「管理员」PowerShell
New-NetFirewallRule -DisplayName "MuseumDocentAI Backend" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
```

## 6. 常见错误对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| `Could not find a version that satisfies the requirement zvec` | Python 不是 3.14 / 不是 64 位 / 不是 Windows | `py -0p` 确认；装 Python 3.14 x64 |
| `... is not digitally signed` / `无法加载文件 ...ps1` | PowerShell 执行策略 | 用 `scripts\setup_backend.cmd`，或 `powershell -ExecutionPolicy Bypass -File ...` |
| `UnicodeDecodeError: 'utf-8' codec can't decode ...` | `.env` 被写成 GBK（记事本另存 ANSI、PowerShell `Add-Content`） | 用 VS Code 另存 UTF-8；脚本会检测并提示 |
| `[向量库] 未配置 EMBED_API_KEY` → 检索退回关键词 | `.env` 没填 embedding | 填 `EMBED_*` 后重启 |
| `Address already in use` | 8000 被占（上次没关干净） | `Get-NetTCPConnection -LocalPort 8000 \| ... Stop-Process` |
| 手机上"网络错误" | 地址填错 / 不在同一网段 / 防火墙拦了 | 先在电脑浏览器访问 health 确认服务本身正常，再查 IP 和防火墙 |
| 模拟器连不上 `10.0.2.2` | 电脑开了代理（Clash 等） | 改用 `adb reverse tcp:8000 tcp:8000` |
| 检索结果明显变差 | 索引维度与 `EMBED_MODEL` 不匹配，或索引没建完 | `scripts\build_index.py` 强制重建 |
| 启动报 `LOCK` / 打开索引失败 | 同时起了两个后端进程 | 只能单进程（zvec 是进程内库，一个索引目录只能一个进程打开） |

## 7. 为什么要有 `requirements-lock.txt`

`requirements.txt` 只写包名，装出来的是"当天最新版"。本项目调好的环境是：

```
fastapi 0.143.0 / starlette 1.7.0 / uvicorn 0.54.0 / requests 2.34.2
python-multipart 0.0.32 / numpy 2.5.5 / zvec 0.8.1
```

FastAPI/Starlette 升级有可能改变 SSE 流式推送或 multipart 上传的行为——这类问题排查成本很高，
所以新人一律用锁定清单安装。升级依赖后重新导出：

```powershell
.\.venv\Scripts\python.exe -m pip freeze | Sort-Object > requirements-lock.txt
```

## 8. 如果要变成"公网可用"（超出本次范围，仅备注）

当前是 **局域网直连**（C/S + HTTP/SSE，明文、无鉴权），换机不会改变这一点。
要让外面的人用，需要额外做：内网穿透（cloudflared/ngrok/frp）或云服务器 + 反向代理 + HTTPS，
并且**补上鉴权**（现在任何人拿到地址都能用你的 API 额度）。
